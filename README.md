# pc-privacy-cleaner

회사 PC를 포맷하지 않고 개인 흔적만 지우는 Windows 도구입니다.
휴직이나 장기 부재 전에, 복귀 후에도 계속 사용할 PC를 정리하는 상황을 생각하고 만들었습니다.
PC를 검사해서 개인정보가 있는 곳을 체크박스 목록으로 보여 주고, 체크한 항목만 지웁니다.

## 다운로드

**[pc-privacy-cleaner.zip 내려받기](https://github.com/Bigide19/pc-privacy-cleaner/raw/main/pc-privacy-cleaner.zip)**

1. zip 파일의 압축을 풉니다. zip 안에서 바로 실행하면 동작하지 않습니다.
2. 압축을 푼 폴더에서 `run.bat`을 더블클릭합니다.
3. 처음 한 번은 '연습 모드'로 실행해서 무엇이 지워질지 먼저 확인합니다.

자세한 사용법은 zip 안에 들어 있는 [README.txt](README.txt)에 있습니다.

> [!WARNING]
> 아직 여러 Windows 환경에서 충분히 검증하지 않았습니다. 실제 삭제 전에 반드시 연습 모드로 결과를 확인해 주세요.
> 지운 파일은 휴지통을 거치지 않으며 되돌릴 수 없습니다.

## 정리하는 항목

| 분류 | 내용 |
|---|---|
| 공동인증서 | 개인 NPKI 인증서는 필수 항목입니다. 법인 인증서와 Windows 인증서 저장소는 기본 해제 상태입니다. |
| 브라우저 | Chrome, Edge, 웨일, Brave, Firefox의 비밀번호, 쿠키, 방문 기록, 자동 완성 데이터를 지웁니다. |
| 메신저 | 카카오톡, 텔레그램, 라인, 디스코드의 로그인 데이터와 카카오톡 받은 파일을 지웁니다. |
| 사용 기록 | 최근 문서, 실행 기록, 휴지통, 임시 파일, 클립보드를 지웁니다. |
| 계정 정보 | Windows 자격 증명과 저장된 Wi-Fi를 지웁니다. 둘 다 기본 해제 상태입니다. |
| 개인 파일 | 파일 이름 키워드로 찾은 파일을 보여 줍니다. 기본 해제 상태입니다. |

회사 메일, 팀즈, 슬랙 같은 업무 프로그램 데이터는 건드리지 않습니다.

## 요구 사항

- Windows 10 이상, Windows PowerShell 5.1 (Windows 기본 포함)
- 관리자 권한은 선택 사항입니다. 없으면 현재 사용자만, 있으면 PC의 모든 사용자를 검사합니다.

## 개발

| 파일 | 역할 |
|---|---|
| `Clean-PersonalData.ps1` | 검사와 삭제를 수행하는 WinForms 스크립트입니다. UTF-8 with BOM, CRLF로 저장합니다. |
| `run.bat` | 더블클릭 런처입니다. ASCII 문자만 사용합니다. |
| `README.txt` | 사용자용 안내입니다. zip에 함께 들어갑니다. |
| `build-zip.sh` | 위 세 파일로 `pc-privacy-cleaner.zip`을 다시 만듭니다. |

소스를 고친 뒤에는 `./build-zip.sh`를 실행하고 zip도 함께 커밋합니다.
인코딩이 바뀌면 PowerShell 5.1에서 한글이 깨지므로, `.gitattributes`로 줄바꿈 변환을 막아 두었습니다.
