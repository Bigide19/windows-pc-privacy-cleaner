개인정보 정리 도구 사용 안내

회사 PC를 포맷하지 않고 개인 흔적만 지우는 도구입니다.
PC를 검사해서 개인정보가 있는 곳을 목록으로 보여 주고, 체크한 항목만 지웁니다.
업무 프로그램과 업무 파일은 그대로 둡니다.


[시작하기 전에]

1. 공동인증서 사본이 다른 곳에 있는지 확인합니다.
   이 도구는 개인 공동인증서를 반드시 지웁니다. 휴대폰, USB, 집 PC에 사본이 없다면
   은행 사이트의 '인증서 내보내기'로 먼저 옮겨 두세요.
2. 크롬, 엣지, 카카오톡은 미리 닫아 두면 편합니다.
   켜져 있으면 지울 때 닫아도 되는지 물어봅니다.
3. 회사 보안 프로그램이 이 도구 실행을 막거나 경고를 띄울 수 있습니다.
   걱정되면 IT 담당자에게 먼저 물어보세요.


[실행 방법]

1. zip 파일을 마우스 오른쪽 버튼으로 누르고 [압축 풀기]를 합니다.
   압축을 풀지 않고 zip 안에서 바로 실행하면 기록 파일이 임시 폴더에 생겨서 찾기 어렵습니다.
2. 압축을 푼 폴더에서 PcPrivacyCleaner.exe(파란 방패 아이콘)를 더블클릭합니다.
   파란 'Windows의 PC 보호' 창이 나오면 [추가 정보]를 누른 뒤 [실행]을 누릅니다.
   따로 설치할 것은 없습니다. Windows 10, 11에 기본으로 들어 있는 기능만 사용합니다.
   처음 실행할 때는 Windows가 파일을 검사하느라 창이 뜨기까지 10초쯤 걸릴 수 있습니다.
3. '사용 전 확인' 창이 나오면 내용을 읽고 [동의하고 시작]을 누릅니다.
   그러면 바로 검사를 시작합니다. 보통 1분 안에 끝납니다.
   검사하는 동안에도 창을 움직일 수 있고, [중지]를 누르면 그때까지 찾은 것만 보여 줍니다.
4. 처음 한 번은 아래쪽 '연습 모드'를 체크하고 [연습 실행]을 눌러 봅니다.
   실제로 지우지 않고, 무엇을 지울지만 기록 파일에 남깁니다.
5. 목록을 확인하고 체크를 조정한 뒤, 연습 모드를 끄고 [선택 항목 삭제]를 누릅니다.


[화면 보는 법]

- 왼쪽은 검사 결과 목록이고, 오른쪽은 고른 항목의 설명입니다.
  목록에서 항목을 누르면 오른쪽에 두 가지가 나옵니다.
  '찾은 내용': 비밀번호가 저장된 사이트, 최근에 연 파일 이름처럼 어떤 개인정보가 있는지 보여 줍니다.
  '지우는 범위': 정확히 어떤 파일을 지우는지 보여 줍니다. 여기에 없는 파일과 폴더는 건드리지 않습니다.
- 비밀번호, 카드 번호, 복사해 둔 내용 같은 값은 화면에 표시하지 않습니다. 사이트 이름과 개수만 보여 줍니다.
- 빨간 글씨 [필수]: 개인 공동인증서입니다. 체크를 풀 수 없습니다.
- 회색 [지울 수 없음]: 지금은 지울 수 없는 항목입니다. 오른쪽 설명에 이유와 방법이 적혀 있습니다.
- 처음부터 체크가 꺼진 항목: 업무용과 섞여 있을 수 있는 항목입니다.
  법인 인증서, Windows에 저장된 인증서와 로그인 정보, Wi-Fi, 파일 이름으로 찾은 개인 파일이 여기에 해당합니다.
  하나씩 보고 개인 것만 체크하세요. 개인 파일이 많으면 [개인 파일 전체]를 누른 뒤 업무 파일만 끄면 됩니다.
- 브라우저 항목에 '브라우저가 켜져 있어서 내용을 읽지 못했습니다'가 나오면, 그 브라우저를 닫고 [다시 검사]를 누르세요.


[브라우저 항목이 회색으로 나올 때]

엣지나 크롬에 계정(회사 계정 포함)이 로그인되어 있으면 비밀번호와 방문 기록이 계정에 동기화됩니다.
이 상태에서는 파일을 지워도 다시 생기기 때문에, 브라우저에서 직접 지워야 합니다.

1. 해당 브라우저에서 Ctrl + Shift + Delete 를 누릅니다.
2. 시간 범위를 '전체 기간'으로 고릅니다.
3. 검색 기록, 쿠키, 비밀번호, 자동 채우기 데이터를 체크하고 [지금 지우기]를 누릅니다.
4. 개인 구글 계정이나 네이버 계정으로 로그인했다면, 지운 뒤 브라우저에서 로그아웃합니다.


[관리자 권한]

관리자 권한 없이 실행하면 지금 로그인한 사용자만 정리합니다.
[관리자로 실행]을 누르면 PC의 다른 사용자 폴더까지 검사합니다.
관리자 비밀번호를 IT 담당자가 대신 입력해야 하는 PC라면 이 버튼을 쓰지 마세요.
그렇게 실행하면 IT 담당자 계정으로 동작해서, 내 계정의 인증서, 로그인 정보, 사용 기록이 빠집니다.


[끝나고 나서]

- 실행 창 기록 같은 일부 항목은 로그아웃했다가 다시 로그인하면 완전히 사라집니다.
- 쿠키를 지웠기 때문에 복귀 후에는 업무 사이트에 다시 로그인해야 합니다.
- 도구 폴더에 log-날짜.txt 기록 파일이 생깁니다. 지운 파일 이름이 적혀 있으므로,
  문제가 없다면 압축 파일과 도구 폴더를 모두 지우고 휴지통을 비워 주세요.
- 문제가 생기면 창 오른쪽 아래의 [문제 알리기]를 눌러 알려 주세요.
  브라우저에서 제보 양식이 열리고, 앱 버전, Windows 버전, 진행 기록이 자동으로 채워집니다.
  진행 기록에는 검사와 삭제 단계, 개수, 오류 종류만 들어가고 파일 이름과 경로는 들어가지 않습니다.
  보내기 전에 양식에서 내용을 확인하고 고칠 수 있습니다.
  파일 이름, 사이트 이름 같은 개인정보는 적지 마세요.
- 프로그램이 오류로 꺼지면, 다음에 실행할 때 지난 오류를 알릴지 물어봅니다.
  이를 위해 프로그램이 켜져 있는 동안 도구 폴더에 run-숫자.tmp 파일이 생겼다가,
  정상으로 끝나면 사라집니다.


[이 도구가 하지 않는 것]

- 회사 메일(Outlook), 팀즈, 슬랙 같은 업무 프로그램 데이터는 건드리지 않습니다.
- 은행 보안 프로그램을 삭제하지 않습니다. 필요하면 [설정] > [앱]에서 직접 지우세요.
- 지운 파일을 복구할 수 없게 덮어쓰지는 않습니다.
- 인터넷에 접속하거나 정보를 밖으로 보내지 않습니다.
  [문제 알리기]도 브라우저로 양식을 열기만 하고, 보내기는 직접 누를 때만 됩니다.


[면책 조항]

이 프로그램은 무료로, 있는 그대로 제공합니다.
개발자는 프로그램이 모든 환경에서 올바르게 동작한다고 보증하지 않습니다.
프로그램을 사용해서 생긴 데이터 손실이나 그 밖의 손해에도 책임지지 않습니다.
무엇을 삭제할지는 사용자가 직접 고르며, 회사 PC에서 쓸 때는 회사 보안 규정을 먼저 확인해야 합니다.
자세한 조건은 함께 들어 있는 LICENSE.txt(MIT 라이선스)를 따릅니다.
