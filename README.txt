개인정보 정리 도구 사용 안내

회사 PC를 포맷하지 않고 개인 흔적만 지우는 도구입니다.
PC를 검사해서 개인정보가 있는 곳을 목록으로 보여 주고, 체크한 항목만 지웁니다.


[시작하기 전에]

1. 공동인증서 사본이 다른 곳에 있는지 확인합니다.
   이 도구는 개인 공동인증서를 반드시 지웁니다. 휴대폰, USB, 집 PC에 사본이 없다면
   은행 사이트의 '인증서 내보내기'로 먼저 옮겨 두세요.
2. 크롬, 엣지, 카카오톡은 미리 닫아 두면 편합니다.
   켜져 있으면 삭제할 때 자동으로 닫을지 물어봅니다.
3. 회사 보안 프로그램이 이 도구 실행을 막거나 경고를 띄울 수 있습니다.
   걱정되면 IT 담당자에게 먼저 물어보세요.


[실행 방법]

1. zip 파일을 마우스 오른쪽 버튼으로 누르고 [압축 풀기]를 합니다.
   압축을 풀지 않고 zip 안에서 바로 실행하면 동작하지 않습니다.
2. 압축을 푼 폴더에서 run.bat 을 더블클릭합니다.
   파란 'Windows의 PC 보호' 창이 나오면 [추가 정보]를 누른 뒤 [실행]을 누릅니다.
3. 창이 뜨면 자동으로 검사를 시작합니다. 1~2분 정도 기다립니다.
4. 처음 한 번은 아래쪽 '연습 모드'를 체크하고 [연습 실행]을 눌러 봅니다.
   실제로 지우지 않고, 무엇을 지울 예정인지만 아래 로그 칸과 로그 파일에 남깁니다.
5. 목록을 확인하고 체크를 조정한 뒤, 연습 모드를 끄고 [선택 항목 삭제]를 누릅니다.


[목록 보는 법]

- 빨간 굵은 글씨 [필수]: 개인 공동인증서입니다. 체크를 풀 수 없습니다.
- 회색 [처리 불가]: 지금은 지울 수 없는 항목입니다. '상세' 칸에 이유와 방법이 적혀 있습니다.
- 처음부터 체크가 꺼진 항목: 업무용과 섞여 있을 수 있는 항목입니다.
  법인 인증서, Windows 인증서 저장소, 자격 증명, Wi-Fi, 파일 이름으로 찾은 개인 파일이 여기에 해당합니다.
  하나씩 보고 개인 것만 체크하세요. 개인 파일이 많으면 [개인 파일 모두 체크]를 누른 뒤 업무 파일만 끄면 됩니다.
- 항목 위에 마우스를 올리면 상세 내용 전체가 보입니다.


[브라우저 항목이 회색으로 나올 때]

엣지나 크롬에 계정(회사 계정 포함)이 로그인되어 있으면 비밀번호와 방문 기록이 계정에 동기화됩니다.
이 상태에서는 파일을 지워도 다시 내려오기 때문에, 브라우저에서 직접 지워야 합니다.

1. 해당 브라우저에서 Ctrl + Shift + Delete 를 누릅니다.
2. 시간 범위를 '전체 기간'으로 고릅니다.
3. 검색 기록, 쿠키, 비밀번호, 자동 채우기 데이터를 체크하고 [지금 지우기]를 누릅니다.
4. 개인 구글 계정이나 네이버 계정으로 로그인했다면, 지운 뒤 브라우저에서 로그아웃합니다.


[관리자 권한]

관리자 권한 없이 실행하면 지금 로그인한 사용자만 정리합니다.
[관리자 권한으로 다시 실행]을 누르면 PC의 다른 사용자 폴더까지 검사합니다.
관리자 비밀번호를 IT 담당자가 대신 입력해야 하는 PC라면 이 버튼을 쓰지 마세요.
그렇게 실행하면 IT 담당자 계정 기준으로 동작해서 내 인증서 저장소, 자격 증명, 실행 기록이 빠집니다.


[끝나고 나서]

- 실행 창 기록 같은 일부 항목은 로그아웃 후 다시 로그인하면 완전히 반영됩니다.
- 쿠키를 지웠기 때문에 복귀 후에는 업무 사이트에 다시 로그인해야 합니다.
- 도구 폴더에 log-날짜.txt 파일이 생깁니다. 지운 파일 이름이 적혀 있으므로,
  문제가 없다면 압축 파일과 도구 폴더를 모두 지우고 휴지통을 비워 주세요.
- 문제가 생기면 로그 파일과 화면 사진을 보내 주세요.


[이 도구가 하지 않는 것]

- 회사 메일(Outlook), 팀즈, 슬랙 같은 업무 프로그램 데이터는 건드리지 않습니다.
- 은행 보안 프로그램을 삭제하지 않습니다. 필요하면 [설정] > [앱]에서 직접 지우세요.
- 지운 파일을 덮어써서 복구 불가능하게 만들지는 않습니다.
